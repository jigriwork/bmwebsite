# Hero Video Placement

To enable the cinematic hero section, place your optimized store video files here with these exact names:

- `brandmark-hero.mp4` (required)
- `brandmark-hero.webm` (optional but recommended)

Recommended specs for fast loading:

- Duration: 8–12 seconds
- Resolution: 1920×1080 or 1280×720
- Codec: H.264 (MP4) and VP9 (WebM)
- Bitrate target: ~2–4 Mbps
- Muted, seamless loop, no hard cuts

The site already includes:

- Video preload hint
- Autoplay muted loop setup
- Poster fallback image
- JS fallback if video fails to load
